# Apis numeric database — attribution and licence

Contains information from **Fore wings of honey bees (Apis mellifera) from
northwestern Europe**, version 2 (2026), by Julita Machlowska, Dariusz Gerula,
Andrzej Oleksa, Henk Kok, Grace McCormack, Alexandra Valentine, Lars Kirkerud,
Per Kryger, Laima Blažytė-Čereškienė, Martin Hasselmann, Teweldemedhn G. Hailu,
Benjamin Rutschmann and Adam Tofilski. Zenodo:
https://doi.org/10.5281/zenodo.18845767.

The publisher's archived `source-record.json` declares Open Database License
(ODbL) 1.0: https://opendatacommons.org/licenses/odbl/1-0/.
Keep this notice and licence URI when redistributing the database.

The numeric database in `originals/*.csv` and `references.json` is made available
under ODbL 1.0, including any database rights Wingmate's contributors hold in
the adaptations. The full adapted collection is supplied in machine-readable
form as [references.json](references.json), with unchanged source CSVs and the
offline recipe `scripts/build-apis-references.py`. Attribution, source hashes
and alterations are embedded in the collection. Public outputs should retain
an associated source and ODbL notice; database adaptations and combinations
must preserve the applicable attribution and share-alike obligations.

Adaptations join source files by exact filename, exclude two unmatched German
wings, and select one wing per colony. Original coordinates are unchanged.
No subspecies labels or worker identities are inferred. Details are in
[README.md](README.md). Wingmate's collection is not endorsed by the authors.

No source photographs or journal figure crops are redistributed. ODbL covers
database rights and does not itself grant copyright permissions for individual
photographs (section 2.4). This notice does not change the separate application
code licence. The complete source citation is in the collection and
[CITATION.cff](CITATION.cff).
